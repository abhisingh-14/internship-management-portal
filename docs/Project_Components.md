# Internship Management Portal
# Component Breakdown

This document divides the Internship Management Portal into independent implementation components.

Each component should:

- Be implemented in its own AI chat.
- Follow all Project Knowledge documents.
- Be production-ready.
- Generate complete files only.
- Follow MVC architecture.
- Use Bootstrap 5 only.
- Use React + Vite frontend.
- Use Node.js + Express backend.
- Use MySQL database.
- Use JWT authentication.
- Follow Coding Standards.
